# HACheckBaby

Lokales, smartes Babyphone für Home Assistant auf Basis von Frigate, geplant als HACS-Integration.

**Status:** Planungsphase, noch kein installierbarer Code.

Der vollständige Plan steht in [docs/MASTERPLAN.md](docs/MASTERPLAN.md).

**Wichtig:** HACheckBaby ist kein Medizinprodukt und kann den plötzlichen Kindstod nicht verhindern. Es ergänzt die Aufsicht durch die Eltern und die Regeln für sicheren Babyschlaf, es ersetzt sie nicht.
